# SevaTrust - UnityConnect

A modern, responsive web application for SevaTrust NGO, built to empower communities through digital connection.

## 🚀 Getting Started

### Prerequisites
- Node.js installed on your machine.

### Installation
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌟 Features

- **Home Page**: Impactful hero section, statistics, and current events.
- **Role Selection**: Dedicated paths for Admins, Volunteers, and Donors.
- **Volunteer Dashboard**: Track hours, view assignments, and manage schedule.
- **Donation Portal**: Easy-to-use interface for donating physical goods (Clothes, Books, etc.).
- **Admin Dashboard**: Campaign management and progress tracking.
- **Responsive Design**: Fully optimized for mobile and desktop using Tailwind CSS.

## 🎨 Design System

- **Primary Color**: Teal (`#0d9488`)
- **Secondary Color**: Orange (`#f97316`)
- **Fonts**: Outfit (Headings) & Inter (Body)

## 🛠️ Tech Stack

- [Next.js](https://nextjs.org/) - React Framework
- [Tailwind CSS](https://tailwindcss.com/) - Styling
- [TypeScript](https://www.typescriptlang.org/) - Type Safety
- [Lucide React](https://lucide.dev/) - Icons
